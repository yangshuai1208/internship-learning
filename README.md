# 嵌入式工程实践与传感器技术学习

## 一、仓库介绍

本仓库用于记录2026年10月起的嵌入式工程实践学习、传感器基础知识、MCU开发、上位机通信及工程测试方法。

主要目标是将已有的STM32、ESP32、FreeRTOS和Linux C/C++技术基础，进一步应用到真实工程场景中，提升嵌入式软件开发、设备联调、故障定位和技术文档编写能力。

本仓库仅用于个人通用技术知识总结，不包含企业内部代码、固件、产品图纸、客户资料、内部通信协议及未经授权的测试数据。

## 二、技术学习方向

### 1. MCU嵌入式开发

- C/C++嵌入式编程
- HC32F460与STM32开发基础
- GPIO、ADC、UART、Timer、DMA
- 中断处理与外设驱动
- 固件烧录、启动和调试

### 2. 传感器技术

- 柔性压力传感器基础
- 压阻效应及信号采集
- NTC温度传感器
- PVDF压电传感器
- ADC采样与数据处理
- 滤波、标定及误差分析

### 3. 上位机与通信

- UART、RS485通信原理
- 数据帧解析
- 上位机设备连接与数据展示
- 通信异常定位
- MCU与上位机联调流程

### 4. 工程测试与故障分析

- 传感器功能测试
- 连接可靠性分析
- 抗压与弯折测试原理
- 故障复现及定位
- 测试报告与SOP编写
- 产品可维护性分析

## 四、学习方法

采用以下工程学习流程：

1. 理解技术原理
2. 阅读相关技术文档
3. 完成基础操作与实验
4. 观察运行现象
5. 分析问题并进行验证
6. 记录技术收获和改进方向

坚持以实际验证结果为依据，区分已经掌握的能力与仍需学习的知识。
